What is MCP?

The Model Context Protocol is an open standard introduced by Anthropic in November 2024. It lets an AI assistant call tools inside other software, the same way for every program. An MCP server is the small bridge that exposes what a program can do.

1

You ask

You write a request to an AI assistant: “list every door without a fire rating” or “block out a two-storey house”.

2

The server translates

The MCP server turns the request into real commands for Revit, SketchUp, Rhino, Blender or whatever program it is built for.

3

The software acts

The program runs the commands inside your project and the result comes back to the assistant, which can then keep going.

AI assistant→MCP server→Revit · SketchUp · Rhino · Blender …

FAQ

  
Is this list complete?
It is a large, verified snapshot and it keeps growing, but new servers appear every week. If one is missing, open an issue or send a pull request.

  
Do these work with ChatGPT, Cursor or other AI apps?
MCP is supported by many AI apps, not only Claude. Each server’s README says which clients it was tested with.

  
Does every program have a server?
No. Some programs have several, some have none yet. Servers for tools like Revit, Rhino and Blender are the most developed.

  
Why is a server marked “Stale”?
Its repository has not been updated for more than 12 months. It may still work, but check the issues and the supported software versions first.

  
Are you affiliated with Autodesk, Trimble, McNeel or any listed project?
No. This is an independent list. Names and logos belong to their owners.

  
How do I add or correct an entry?
Edit data/servers.json in the GitHub repository and open a pull request, or use the “Add or update a server” issue form. The rules are in CONTRIBUTING.md.
